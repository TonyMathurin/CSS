Onderzoek HTML & CSS.

1. Waarom noem je de eerste HTML-pagina meestal index.html?

index.html is een soort standaardnaam voor de hoofdpagina van een website. Als je bijvoorbeeld naar een website gaat zonder een specifieke bestandsnaam op te geven, kan de webserver automatisch het bestand index.html openen. Daardoor hoef je niet steeds /index.html achter het webadres te zetten. Het is dus vooral een afspraak die door webservers en ontwikkelaars veel wordt gebruikt.

2. Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

Tegenwoordig werken webontwikkelaars met de HTML Living Standard van WHATWG. De officiële specificatie noemt zichzelf ook daadwerkelijk de "HTML Living Standard". Het woord Living betekent dat HTML niet meer wordt gezien als een standaard die af en toe een volledig nieuwe versie krijgt. De standaard wordt voortdurend bijgewerkt wanneer nieuwe functies worden toegevoegd, aangepast of verwijderd. Daarom spreken we tegenwoordig meestal gewoon over HTML, in plaats van bijvoorbeeld HTML5 als een aparte, vaste versie

3. Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

CSS wordt tegenwoordig ontwikkeld in verschillende modules. Elke module kan zich in een ander stadium van ontwikkeling bevinden en een eigen versienummer hebben. Er is daarom niet één nieuwe versie waarin alle CSS-functies tegelijk worden vernieuwd. Je kunt bijvoorbeeld te maken hebben met een bepaalde versie van de CSS Color-module en tegelijkertijd met een andere versie van een module voor layout. De W3C maakt daarnaast regelmatig zogenaamde CSS Snapshots, waarin de stabiele onderdelen van CSS op een bepaald moment worden verzameld.

4. Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?

Browsers moeten HTML en CSS verwerken en omzetten naar wat je op je scherm ziet. Verschillende browsers gebruiken verschillende rendering-engines. Chrome gebruikt bijvoorbeeld Blink, Firefox Gecko en Safari WebKit. Ook worden nieuwe webfuncties niet altijd op hetzelfde moment door iedere browser ondersteund. Daardoor kan een bepaalde CSS-eigenschap of HTML-functie in de ene browser anders werken of nog niet beschikbaar zijn in een andere browser. Daarnaast kunnen bijvoorbeeld lettertypes, standaardinstellingen en de manier waarop bepaalde onderdelen worden getekend kleine verschillen veroorzaken. Daarom testen webontwikkelaars websites vaak in meerdere browsers.

Welke drie webbrowsers worden momenteel wereldwijd het meest gebruikt?

De drie wereldwijd meest gebruikte webbrowsers zijn Google Chrome, Apple Safari en Microsoft Edge. Volgens recente gegevens van analysetool StatCounter verdelen deze drie spelers het overgrote deel van de wereldwijde markt
